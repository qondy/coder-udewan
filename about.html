コーダーの右腕

指示プロンプト・スニペット・納品前チェックを、ひとつに。Web制作のコーディングを、着手から納品まで支える右腕アプリです。

アプリを使ってみる →

できること

指示プロンプトをフォームで作成

「新規コーディング」「スクショで調整依頼」「機能の追加」「納品前レビュー」から選んで、幅や倍率、調整したい箇所を入れるだけ。AIにそのまま渡せる指示文ができあがります。

実装する機能をチェックで選ぶ

ハンバーガーメニュー・モーダル・アコーディオン・カルーセル・お問い合わせフォームなど14種類の定番機能を、チェックするだけで指示文に追加。アクセシビリティや二重送信防止など、実装時の注意点も自動で添えます。

ルールを毎回自動で入れる

セマンティック+BEM・SCSS・TypeScript・npm run build で dist/ をFTP納品、というコーディングルールを指示文に自動で入れます。デフォルトは「セマンティック+BEM ／ SCSS、TS ／ npm run build→dist→FTP等」の3行で、命名規則や画像の扱いまで書いた詳しい版にも切り替えられます。

「コーディングして」だけで伝わる

「ルール設定」タブで、Claude・Claude Code・GitHub Copilot・Cursor・ChatGPT 向けのルール設定を作れます。一度入れておけば、あとはカンプ画像を貼って「コーディングして」と送るだけで、毎回ルールどおりに実装されます。

スクショでの調整依頼も整理

「箇所・現状・希望」を最大10件まで並べて入力。スクショに書いた番号とそろえておけば、伝わりやすい修正依頼になります。

テンプレートとして保存

いつもの幅・倍率・ブレークポイントなどを名前を付けて保存し、ワンタップで呼び出せます。入力中の内容はブラウザに下書きとして残ります。

スニペットをワンタップでコピー

ヘッダー・mixin・ハンバーガーメニューなど、案件ごとに書くコードを登録。コード部分をタップするだけでコピーできます。定番5つのサンプル付き。

言語別・キーワードで検索

HTML / SCSS / TypeScript などの言語で絞り込み、タイトル・メモ・コードの中身までまとめて検索。よく使うものほど上に並びます。

納品前チェックリスト

案件を作ると、着手前のヒアリング項目（12項目）と納品前チェック（40項目）がまとめて用意されます。進み具合はバーと%で一目でわかります。

案件ごとに項目を追加

その案件だけの確認項目を、好きなグループに追加できます。未チェックの項目だけをコピーして、AIに確認を頼むこともできます。

カテゴリーで整理できるメモ

打ち合わせ・修正依頼・作業ログ・アイデアなど、カテゴリーを付けてメモを整理。カテゴリーをタップして絞り込み、案件ごとの表示や検索、ピン留め、ワンタップコピーもできます。ひな形を挿入するとカテゴリーも自動で入り、本文のURLはそのままリンクになります。

スマホとPCで同じデータ

Googleでログインすると、テンプレート・スニペット・案件・メモはあなた専用の領域に保存され、スマホでもPCでも同じものを使えます。

使い方

1

Googleでログイン：テンプレート・スニペット・案件はあなた専用の領域に保存されます。

2

AIにルールを覚えさせる（最初に1回）：「ルール設定」タブで使うAIを選び、コピーまたはファイル保存して設定します。以降はカンプ画像を貼って「コーディングして」と送るだけで、指示文を作らなくてもルールどおりに実装されます。

3

指示プロンプトを作る：依頼の種類を選び、案件名・ページ名・幅などを入力。つけたい機能（ハンバーガーメニュー・モーダルなど）はチェックで選べます。右（スマホでは下）にできあがった指示文が表示されます。

4

コピーしてAIに貼り付け：「指示文をコピー」を押し、Claude Code などの入力欄にカンプ画像やスクリーンショットと一緒に貼り付けて送信します。

5

よく使うコードはスニペットに：「定番を5つ入れてみる」で雰囲気をつかんでから、自分のコードを登録していくのがおすすめです。

6

納品前はチェックリストで確認：「納品チェック」で案件を作り、項目を1つずつチェック。すべて終わると「納品OK」になります。

7

気づいたことはメモに：「メモ」タブで、打ち合わせや修正依頼をカテゴリー・案件と一緒に残せます。納品チェックの案件画面の「この案件のメモ」からも開けます。

※ 入力中の指示プロンプトの下書きは、お使いの端末のブラウザにだけ保存されます。パスワードやFTPの接続情報などは、スニペットやチェック項目に保存しないでください。
